Guide & Features

Join and invite

Use the link button beside the room code to copy an invitation. Everyone joins with their own display name.

Estimate and reveal

Choose a card to estimate. Votes stay hidden until the host reveals them. Start a new round after the discussion to vote again.

Roles and participation

The host manages reveal, new rounds and room settings. Spectators can follow the session without voting; the host can change participant roles.

Decks and special cards

The host selects the estimation sequence and can enable special cards for questions, breaks, dependencies and other discussion signals.

Topic and automatic reveal

The host can show an estimation topic, add a short title or ticket link, and enable automatic reveal when all active estimators have voted.

Leave or close the room

Leaving the room page removes only you from the session. The separate host action “Close room for everyone” ends the room for all participants.
