About This Tool

RBS' Estimation Poker is a free, lightweight online planning poker tool designed for agile teams. No registration required, just create a room and start estimating.

What is Planning Poker?

Planning Poker (also known as Scrum Poker or Estimation Poker) is a consensus-based technique for estimating effort or relative size of development goals in software development. Team members make estimates by playing numbered cards face-down, then reveal them simultaneously.

This method prevents cognitive bias and anchoring, where the first number spoken influences the rest of the team's estimates.

Why Use This Tool?

  • ⚡ Real-time synchronization across all participants
  • 🚀 No registration or sign-up required
  • 🎴 Multiple card sequences (Fibonacci, T-Shirt sizes, Powers of 2)
  • 🎯 Auto-reveal mode when everyone has voted
  • 🔗 Optional persistent rooms with shareable links
  • 🌍 Multi-language support (English, German)
  • 💯 Completely free and open for all teams

How to Get Started

  1. Enter your name and a room code
  2. Share the invite link with your team
  3. Choose your estimate from the cards
  4. The host reveals all cards when ready
  5. Discuss and re-estimate if needed

Key Features

  • WebSocket-based real-time updates
  • Special cards: Question (❓), Coffee Break (☕), Discussion (💬)
  • Spectator mode for non-voting participants
  • Host controls: reveal, reset, kick, sequence selection
  • Ticket/Story field with JIRA link support
  • Dark and light theme support

Technology

Built with Spring Boot, WebSocket, and vanilla JavaScript for minimal footprint and maximum performance.
